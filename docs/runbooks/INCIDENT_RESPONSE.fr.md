# Réponse aux incidents et violations de données

## Priorités

1. Protéger les personnes et empêcher l'extension.
2. Préserver les preuves sans copier inutilement les données.
3. Identifier les organisations, données, périodes et systèmes concernés.
4. Informer le responsable de traitement sans délai indu.
5. Restaurer depuis une source saine et documenter les mesures.

## Procédure

- ouvrir un identifiant d'incident et noter heure, déclarant et symptômes ;
- révoquer les sessions, invitations, jetons Node ou fournisseurs compromis ;
- isoler le conteneur ou le nœud concerné sans effacer les journaux ;
- changer les secrets dans un ordre évitant les interruptions inutiles ;
- vérifier l'audit TableNow, les accès hôte, SMTP, modèle et sauvegardes ;
- qualifier confidentialité, intégrité, disponibilité et risque pour les personnes ;
- fournir au restaurant les faits connus, catégories, volume, conséquences et remédiations ;
- aider le restaurant à décider d'une notification CNIL sous 72 heures et, si nécessaire, aux personnes ;
- réaliser un retour d'expérience avec actions, responsables et échéances.
