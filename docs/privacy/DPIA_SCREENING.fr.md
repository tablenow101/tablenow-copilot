# Évaluation de nécessité d'une AIPD — cadrage pilote

Une AIPD n'est pas automatiquement requise pour un simple cockpit de restaurant. Elle doit néanmoins être réévaluée avant chaque intégration réelle, notamment si TableNow combine à grande échelle : profilage systématique, données de santé détaillées, enregistrements vocaux, surveillance des salariés, décisions ayant un effet significatif ou rapprochement de sources multiples.

## Garde-fous du pilote

- données fictives par défaut ;
- enregistrements audio désactivés ;
- aucune décision RH, financière ou juridique autonome ;
- allergènes limités au besoin opérationnel ;
- validation humaine des actions sensibles ;
- modèle local/déterministe disponible ; cloud et apprentissage désactivés par défaut ;
- durées et finalités visibles dans l'application.

## Déclencheurs de nouvelle analyse

- branchement téléphonie avec enregistrement ou transcription ;
- analyse de performance individuelle des salariés ;
- scoring comportemental ou prédiction de no-show à grande échelle ;
- données biométriques, géolocalisation ou paiement ;
- déploiement groupe dépassant les hypothèses du pilote ;
- changement de fournisseur, région ou finalité IA.

La décision finale, les risques, mesures et validation DPO/conseil doivent être consignés avant activation.
