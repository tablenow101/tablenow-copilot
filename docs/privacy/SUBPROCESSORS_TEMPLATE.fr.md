# Registre des sous-traitants ultérieurs — modèle

Le registre de production doit être publié avec le pays, la finalité, les garanties de transfert et la date d'ajout. Aucun fournisseur ci-dessous n'est activé par la seule présence de son adaptateur.

| Catégorie | Option cloud envisagée | Option locale |
| --- | --- | --- |
| Hébergement console | Vercel | conteneur TableNow Node |
| PostgreSQL | Supabase ou hébergeur européen | PostgreSQL du client |
| E-mail transactionnel | Resend/SMTP choisi | serveur SMTP du client/Mailpit test |
| Modèle IA | fournisseur explicitement activé | Ollama/vLLM local |
| Stockage | S3 compatible configuré | disque chiffré local |

Avant activation pilote réelle, compléter les entités juridiques, régions, DPA et mécanismes de transfert.
