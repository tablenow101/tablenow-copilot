# D-015 — Priorité onboarding et indépendance de l'outil d'exécution

Date : 6 septembre 2026.
Statut des principes : validés explicitement par le fondateur dans la conversation.
Statut de la spécification détaillée : finalisation CTO/PO à vérifier sur Preview avant fusion.

## Décisions du fondateur

- La PR #12 reste 100 % technique. Aucun nouveau chantier d'infrastructure avant la finalisation UX.
- L'onboarding complet est le chantier produit prioritaire, dans une PR indépendante.
- Chaque écran précise texte exact, choix/composants, voix/prompts, logique conditionnelle et données réellement persistées.
- La sortie délivre immédiatement un premier résultat personnalisé utile ; aucun cockpit vierge ni faux résultat.
- La recette porte sur les parcours dans un navigateur réel, desktop et mobile, pas seulement sur le code.
- Le référentiel, les règles, les tests et les garde-fous appartiennent au dépôt et s'appliquent à tout agent ou développeur futur. Codex est remplaçable.
- Le CTO/PO doit reprendre le contexte déjà validé, agir dans le périmètre délégué et éviter de redemander les mêmes décisions au fondateur.
