# Mode local futur

Le pilote reste sur Vercel : aucun nouveau VPS n'est nécessaire.

Le futur TableNow Node pourra exécuter certaines fonctions dans le restaurant quand le besoin hors ligne est confirmé. Il sera un exécuteur autorisé ou une installation explicitement choisie, jamais un second backend cloud qui écrit en parallèle par défaut.

## Condition d'activation

Le mode local ne sera activé qu'après avoir défini : propriété des données, synchronisation, résolution des conflits, mises à jour, sauvegarde, support et procédure de retour au cloud.
