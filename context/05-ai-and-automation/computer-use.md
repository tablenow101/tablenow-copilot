# Computer Use

Computer Use permet au Copilot d'utiliser un site ou un logiciel comme un humain lorsque le restaurant l'autorise et qu'aucune connexion plus fiable n'existe.

## Ordre obligatoire

1. fonction native TableNow ;
2. API officielle ;
3. import, export ou calendrier ;
4. outil MCP contrôlé ;
5. Computer Use assisté ;
6. instruction manuelle à l'utilisateur.

## Garde-fous

- connexion propre à chaque restaurant ;
- domaines autorisés explicitement ;
- identifiants référencés dans un coffre, jamais stockés en clair dans la base ;
- procédure versionnée et testée ;
- aperçu avant les actions sensibles ;
- arrêt immédiat en cas d'écran inattendu, doute ou changement critique ;
- vérification après action et preuve horodatée ;
- bouton d'annulation et journal complet.

Computer Use ne peut pas être garanti exact à 100 % face à un site externe qui change ; TableNow garantit en revanche qu'il bloque, demande ou revient à l'humain plutôt que d'inventer une réussite.
