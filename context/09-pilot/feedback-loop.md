# Boucle de feedback

1. Le testeur peut envoyer un retour depuis l'écran concerné.
2. TableNow joint version, route, appareil et contexte non sensible.
3. Le retour reçoit un statut : reçu, qualifié, planifié, livré ou refusé.
4. Un problème critique ouvre immédiatement une procédure d'incident.
5. Une amélioration livrée est vérifiée avec le testeur d'origine.

Les retours ne doivent jamais servir à entraîner un modèle sans choix explicite et base juridique adaptée.
