# Glossaire simple

| Mot | Explication courte |
|---|---|
| API | Porte contrôlée par laquelle deux logiciels échangent. |
| Backend | Partie invisible qui applique les règles et enregistre les données. |
| Base de données | Mémoire structurée et durable du produit. |
| Computer Use | Agent qui utilise une interface comme un humain quand aucune meilleure connexion n'existe. |
| Déploiement | Mise en ligne d'une version précise du produit. |
| Environnement | Copie isolée du produit pour développer, tester ou produire. |
| Idempotence | Protection qui empêche une même action d'être exécutée deux fois. |
| MCP | Standard qui expose des outils contrôlés à une IA. |
| Migration SQL | Modification versionnée de la structure de la base. |
| Multi-tenant | Plusieurs restaurants isolés dans une même plateforme. |
| Outbox | File fiable des événements à envoyer sans les perdre ni les doubler. |
| PostgreSQL | Moteur de base de données ouvert et portable choisi pour TableNow. |
| RLS | Barrière de base qui empêche un restaurant de voir les données d'un autre. |
| Responsive | Interface adaptée réellement à chaque taille d'écran. |
| Source de vérité | Endroit unique dont la donnée fait foi. |
| Vercel | Plateforme cloud qui construit et héberge TableNow Copilot. |
| Workflow | Suite d'étapes contrôlées menant à un résultat. |
