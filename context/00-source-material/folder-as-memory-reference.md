# Référence « dossiers comme mémoire »

La référence visuelle fournie montre une arborescence numérotée où chaque domaine contient ses sources, principes, idées, productions et fichiers `CONTEXT.md`.

TableNow reprend ce principe avec trois adaptations :

1. chaque dossier explique son rôle dans un `CONTEXT.md` ;
2. l'état courant et les blocages ont un espace dédié ;
3. les décisions d'architecture sont séparées des idées afin qu'une hypothèse ne devienne jamais une règle par accident.
