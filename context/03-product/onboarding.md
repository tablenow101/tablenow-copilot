# Onboarding — priorité produit active

Le chantier actif est l'onboarding complet jusqu'au premier résultat personnalisé et sauvegardé dans le cockpit.

Spécification d'exécution : [ONBOARDING_FINAL.fr.md](../../docs/product/ONBOARDING_FINAL.fr.md).

## Invariants

- La PR #12 reste technique et n'est pas modifiée par ce chantier.
- Aucun nouveau chantier d'infrastructure avant finalisation UX.
- Conversation guidée, choix visibles, texte et voix accessibles ensemble.
- Préremplissage uniquement à partir de sources connues ; confirmation des faits et règles.
- Adaptation à l'existant, sans fausse connexion ni activation extérieure.
- État réellement sauvegardé côté serveur, reprise et correction sans perte.
- Premier plan/brouillon métier personnalisé, pas un dashboard vierge ou des métriques inventées.
- Tests navigateur desktop/mobile avec preuves, au-delà des tests code.
- Contrat indépendant du fournisseur de l'agent de développement.

## Repères du parcours

Accès existant → établissement → priorité et préférence d'interaction → solution de réservation → fonctionnement conditionnel → validation et note finale → premier résultat → cockpit.

Ces repères regroupent les sujets ; les informations déjà confirmées ne sont pas redemandées. La composition détaillée des zones auparavant ouvertes est une finalisation CTO/PO à vérifier sur Preview, pas une validation visuelle déjà obtenue.
