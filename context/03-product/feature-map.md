# Carte fonctionnelle

| Espace | Résultat attendu |
|---|---|
| Aujourd'hui | Voir les risques, priorités et décisions du service. |
| Communications | Recevoir, qualifier, répondre et tracer les échanges. |
| Réservations | Créer, modifier, confirmer, placer et suivre une réservation. |
| Opérations | Assigner et clôturer les tâches du service. |
| Équipe | Planifier, confirmer et gérer les écarts de présence. |
| Stocks | Suivre les quantités, seuils et besoins de commande. |
| Performance | Comprendre activité, conversion, temps gagné et tendances. |
| Établissements | Piloter chaque site et consolider un groupe. |
| Copilot | Analyser, proposer, faire valider, agir et prouver. |
| Administration | Inviter, attribuer les rôles et contrôler le pilote. |
| Centre RGPD | Gérer préférences, demandes et documents applicables. |

Un bouton n'est considéré fonctionnel que si son action a un état, une persistance, un retour d'erreur et une destination vérifiable.
