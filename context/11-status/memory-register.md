# Mémoire canonique enregistrée

12 septembre 2026 : registre privé `project_memory.records` créé dans la base Copilot stable, avec vue des versions courantes `project_memory.current_records`. 65 enregistrements : décisions consolidées, protocole, catalogue de compétences, orchestration, historique, index des références et archive durable.

La sauvegarde contient 20 écrans HTML Stitch et leurs captures, les autres visuels/logos du dernier export, quatre références utilisateur et l'image générée de restaurant. Les empreintes SHA-256, tailles et dimensions sont indexées. Les fichiers résident dans l'archive durable indexée ; ils ne sont pas stockés comme blobs PostgreSQL.

Le registre conserve les corrections et ne transforme pas les propositions abandonnées en décisions actives. Le rapport sourcé antérieur sur les difficultés des restaurateurs n'a pas été identifié dans ce lot ; ne pas prétendre l'avoir retrouvé. Cette sauvegarde est une consolidation, pas une transcription exhaustive d'anciens échanges inaccessibles. Aucun nouveau parcours UI ni moteur multi-agents n'est déployé par cette opération.
