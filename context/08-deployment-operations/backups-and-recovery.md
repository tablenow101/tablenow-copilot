# Sauvegarde et reprise

- Sauvegardes automatiques de PostgreSQL selon le plan retenu.
- Export chiffré indépendant avant une migration majeure.
- Test de restauration sur un environnement isolé.
- Objectif de perte et délai de reprise définis avant le pilote réel.
- Versions déployées conservées pour un retour applicatif immédiat.
- Procédure écrite pour base, stockage privé et secrets.

Une sauvegarde n'est considérée fiable qu'après une restauration testée.
