# Retour arrière — accès unifié

Avant de retirer l’étape `profile`, terminer ou invalider les challenges encore actifs dans cet état. Le retour arrière consiste ensuite à rétablir la contrainte précédente sur `account_challenges.stage`, limitée à `email`, `enroll` et `mfa`.

Les comptes déjà créés et leurs sessions ne sont pas supprimés.
